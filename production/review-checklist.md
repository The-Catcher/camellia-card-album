# Camellia Sonata Review Checklist

## Theme
- [ ] Camellia is the primary visual identity.
- [ ] Piano details are present but secondary.
- [ ] The mood is classical romantic plus fresh literary.
- [ ] The set does not feel dark gothic, colorful, or text-heavy.

## Card System
- [ ] The cover and six cards feel like one series.
- [ ] Each card has a distinct composition.
- [ ] Numbering is consistent across all cards.
- [ ] Titles are small and do not compete with artwork.

## Palette
- [ ] Only white, ivory, gray, charcoal, and black are used.
- [ ] Gray shadows add depth without becoming muddy.
- [ ] No floral color accents are present.

## Print Readiness
- [ ] Bleed is included in final print exports.
- [ ] Important artwork and text remain inside safe area.
- [ ] Fine linework is thick enough for print.
- [ ] Spot UV, embossing, or debossing areas are clearly marked if used.

## Delivery
- [ ] Cover source artwork is complete.
- [ ] Six card source artworks are complete.
- [ ] Contact sheet is complete.
- [ ] Production notes are complete.
- [ ] Final print PDFs are exported from the approved source files.
