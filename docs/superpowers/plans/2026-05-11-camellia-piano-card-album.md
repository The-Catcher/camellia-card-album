# Camellia Piano Card Album Implementation Plan

**Goal:** Produce a production-ready visual package for the monochrome `Camellia Sonata / 山茶奏鸣` cultural/creative collectible card album.

**Architecture:** The package is split into creative brief, design spec, visual system, cover concept, six card concepts, contact sheet, and production notes. The editable Figma file is the primary design workspace; SVG files are source handoff assets for versioning and print refinement.

**Figma:** https://www.figma.com/design/85QMN12UzNZLp8BwoxkQsj

## Production Steps

1. Review the Figma file and SVG source files for style consistency.
2. Refine line weights and typography in Figma or another vector design tool.
3. Confirm card count, final dimensions, and bilingual title handling.
4. Export print PDFs with 3 mm bleed and 5 mm safe area.
5. Use `production/review-checklist.md` before printer handoff.

## Constraints

- No color accents.
- No heavy explanatory text.
- Camellia remains the primary visual identity.
- Piano details stay secondary and cropped.
- The final set should feel classical romantic plus fresh literary, not dark gothic.
